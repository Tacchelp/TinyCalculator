# Tiny Calculator (Ocaml)
A small project built during Summer Holidays to refresh my Ocaml skills

## Features
- Lexer and Parser
- Supports basic operations (+ , -, *, / and parenthesis)
- Support Integers.

## How to compile and run 
```bash
ocamlopt -o calculator lexer.ml parser.ml main.ml
./calculator
```
then write a calcul.
